# NPC Editor

A visual tool for creating and editing NPCs and creatures.

## Features

- NPC template designer
- AI behavior configuration
- Loot table editor
- Vendor item setup
- Trainer spell configuration
- Model and display settings

## Starting the Editor

```bash
npm run npc-editor
```

The editor will open in your default browser at `http://localhost:3001`
