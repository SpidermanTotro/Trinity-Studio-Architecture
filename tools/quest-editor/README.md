# Quest Editor

A visual tool for creating and editing World of Warcraft quests.

## Features

- Visual quest designer
- Quest chain management
- Objective editor
- Reward configuration
- Preview mode
- Export to database

## Starting the Editor

```bash
npm run quest-editor
```

The editor will open in your default browser at `http://localhost:3000`

## Usage

1. Create a new quest or load existing
2. Configure quest details (name, level, faction, etc.)
3. Add objectives
4. Set rewards
5. Save to database or export
